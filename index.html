📖 Cara Menambah Foto & Album Baru
① Tambah foto ke album yang sudah ada
Buka js/main.js → cari bagian const galleryData = { → tambahkan item baru di dalam array items: [...] milik album yang kamu mau.
Contoh menambah foto di album Hobi:
{ src: 'img/namafile.jpg', title: 'Judul Foto', desc: 'Deskripsi singkat' }, Lalu taruh file fotonya di folder img/
② Tambah album baru (mis. "Kuliah")
Di js/main.js dalam galleryData, tambahkan blok baru:
kuliah: { label : 'Kuliah', icon : '🎓', color : '#2563eb', items : [ { src: 'img/kuliah1.jpg', title: 'Ospek', desc: 'Hari pertama masuk' }, ] }, Lalu di index.html, duplikat salah satu blok <div class="book-album-wrap"> dan ganti data-book="kuliah" dan isi teksnya.
③ Warna sampul buku baru
Di bagian CSS dalam <style> di index.html, tambahkan tema warna baru:
.book-album[data-book="kuliah"] { --book-bg : linear-gradient(155deg,#60a5fa 0%,#2563eb 100%); --book-spine: #1e3a8a; }
